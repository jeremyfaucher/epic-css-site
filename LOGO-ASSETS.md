# Sample brand marks

These monochrome SVGs are used to demonstrate a logo-marquee layout. Their presence does not imply that any organization uses or endorses Epic CSS. The marks remain the property of their respective owners; this folder does not grant a trademark or artwork license.

Source reference: [JetBrains homepage](https://www.jetbrains.com/), organization-logo row, retrieved November 13, 2026.

Each original SVG was downloaded unchanged from `https://resources.jetbrains.com/storage/wtui/logos/<name>_mono.svg`. The local filenames use the same names without `_mono`: volkswagen, citibank, bmw, booking-com, visa, shopify, google, nasa, tesla, x, thoughtworks, valve.

The example injects accessible labels and utility classes when rendering inline, so the marks inherit the site's text color. Replace these sample marks with artwork you are authorized to use for your own production project.
