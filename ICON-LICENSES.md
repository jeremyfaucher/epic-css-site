# SVG provenance

The `src/assets/icons/social/` files adapt `twitter-x.svg`, `linkedin.svg`, `github.svg`
and `rss.svg` from Bootstrap Icons **v1.11.3**:
https://github.com/twbs/icons/tree/v1.11.3/icons

Upstream license: https://github.com/twbs/icons/blob/v1.11.3/LICENSE
The complete MIT notice is retained in `src/assets/licenses/bootstrap-icons-LICENSE.txt` and inside
every standalone adapted SVG, so the notice travels through Copy SVG. The
author card displays clean markup and Copy HTML prepends one consolidated full
MIT notice covering all four icons. This difference is disclosed beside the
example. If clipboard access fails, the selected manual-copy fallback contains
the same complete licensed payload. Geometry is unchanged, proportionally scaled from 16 units to the
gallery's 24-unit viewBox; dimensions and paint use the gallery conventions.
No Bootstrap package or runtime dependency is installed.

These assets are not original Epic CSS artwork. Brand marks remain their owners'
trademarks; this software license does not grant separate trademark rights or
imply endorsement. Review each service's current guidance when reusing marks:

- https://about.x.com/en/who-we-are/brand-toolkit
- https://brand.linkedin.com/downloads
- https://brand.github.com/foundations/logo

Social previews use neutral inherited text color rather than arbitrary accent
colors. The author card's links are labeled demonstrations on example.com, not
real profiles or feeds.

The 21 geometric outline icons and `src/assets/author-placeholder.svg` are original site
demo artwork covered by the site's existing MIT license.
