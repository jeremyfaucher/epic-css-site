<div class="flex-md gap-40">
<div class="flex-2">
<p>Epic CSS gives you simple, unopinionated utilities for layout, spacing, typography, and color. Combine them in your markup and bring your own visual design.</p>

<p><strong>Why ship the whole library when your project uses only a fraction?</strong> Epic Light scans HTML, Nunjucks, and Markdown files in your configured project directory for utility classes, then filters the full compiled CSS into a smaller stylesheet. It keeps base styles and matching responsive blocks alongside the utilities it finds.</p>

<p>Start with <code>npm install epic-css</code> and follow the <a href="/docs/installation/">installation guide</a>, or build on the <a href="/11ty-theme/">Epic CSS 11ty theme</a>. The guide covers Sass setup and the optional <a href="/docs/installation/#light-build">Epic Light build</a>.</p>
