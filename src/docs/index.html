Small utilities, your design

Use the classes together in ordinary markup. These pages document the utilities currently emitted by Epic CSS, with a live example and the same HTML ready to copy. Example borders and numbered tiles are documentation decoration; the layout and color classes come from the library.

Full CSS and a project-specific light build

Pre-light is the whole compiled stylesheet. It contains the utilities available from your Sass imports. The optional light step compares classes found in project source with that CSS and writes a filtered stylesheet. It is a separate production step, not a requirement for using the library.

Read the light-build guide for the commands and scanning limits.
